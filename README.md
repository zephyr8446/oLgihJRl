# 项目简介

## 核心功能
- 基于YOLOv8的玫瑰花与叶病检测系统，支持识别8类病害：Black-Spot、Cercospora-Leaf-Spot、Downy-Mildew、Fresh-Leaf、Powdery-Mildew、Rose、Rose-Botrytis-Blight、Rose-Slug
- 支持2000张标注数据集的完整训练集
- 提供训练好的模型及训练结果
- 支持多种输入源检测：单张图片、图片文件夹、视频文件、本地摄像头
- 界面功能：实时显示目标位置、目标总数、置信度信息；支持批量检测并查看所有结果
- 可自定义检测参数：置信度阈值、IOU阈值
- 支持选择显示标签和原图，可选择不同检测模型
- 包含完整程序文件、UI界面源文件、数据集图片及运行教程

## 适用场景
- 农业种植中玫瑰花病害的早期检测与防治
- 植物保护研究与教学演示
- 园艺管理中的病虫害监测
- 农业智能化系统的视觉检测模块集成

## 技术特点
- 基于Pycharm+Anaconda或VSCode+Anaconda开发环境
- 技术栈：Python3.9、OpenCV-Python、PyQt5、Ultralytics、Torch1.9
- 提供完整的用户界面，支持实时预览与批量处理
- 模型已训练完成，配置环境后可直接使用
